## 🎬 ScrollSequence Component

This project includes a **custom scroll-based animation component** — `ScrollSequence`.  
It renders a **frame-by-frame image sequence** that plays smoothly as the user scrolls through the page, similar to Apple’s product animations.

The effect is achieved using **GSAP + ScrollTrigger**, allowing full control over playback, pinning, and transitions.

### ✨ Features
- Scroll-driven **frame sequence animation**
- Supports **hundreds of images**
- Built-in **pinning** of the section while scrolling
- Optional fade and scale effects for UI elements
- Fully reusable across different pages or sequences
